# dogapp

Бесплатная копия Discord на чистом **HTML + CSS + JS** (без сборки, фреймворков и npm-зависимостей).
Версия 2.0: аккаунты, друзья, звонки, видеозвонки, загрузка фото, шрифт ника и эмоции серверов без смайлов в интерфейсе.

## Что умеет

| Фича | Как работает |
| --- | --- |
| Загрузочный экран | Логотип, анимированные точки, сменяющиеся статусы, прогресс-бар и плавный переход. |
| Интерфейс в стиле Discord | Рельса серверов, каналы с категориями, чат со группировкой сообщений, список участников, ЛС, панель пользователя и адаптив. |
| Регистрация и вход | Полноэкранная форма «Вход / Регистрация»: логин, пароль, отображаемое имя. Аккаунты в `/dogapp/accounts/<login>` (соль + SHA-256 в браузере), профиль привязан к uid, сессия в `localStorage`. Есть гостевой вход, смена пароля и выход. Это демо-авторизация без серверной проверки. |
| Система друзей | Заявки (входящие / исходящие), принять / отклонить / отменить, удалить из друзей, блокировка, поиск по логину или имени. Экран «Друзья» с вкладками «В сети», «Все», «Не в сети», «Ожидают», «Отправленные», «Добавить друга». |
| Звонки | 1:1 голосовые и видеозвонки через **WebRTC**: сигналинг (SDP и ICE-кандидаты) пишется в Firebase RTDB, состояние подтягивается опросом. Входящий звонок, принять/отклонить, микрофон, камера, таймер, завершение. |
| Демо видеозвонки | Кнопка «Демо видеозвонка» и «Демо звонка»: удалённый видеопоток генерируется локально через `canvas.captureStream()`, второй участник не нужен. Автоматически включается, если собеседник не в сети или Firebase недоступен. |
| Голосовые каналы | Клик по голосовому каналу подключает к комнате: список участников, микрофон, кнопка демо-видео и отключение. Присутствие хранится в `/dogapp/voice/<channelId>/<uid>`. |
| Выбор фото | Для аватара и баннера: загрузка файла с устройства, либо ссылка на картинку, либо градиентный пресет. Есть переключатель «Анимация»: для GIF/WEBP без галочки берётся первый кадр и сохраняется статичный PNG, с галочкой анимация сохраняется; для градиента галочка включает плавное движение. |
| Шрифт ника | 8 начертаний в «Настройки → Мой профиль» с предпросмотром. Выбранный шрифт сохраняется в профиле и виден всем в чате, списке участников, профиле и списке друзей. |
| Эмоции серверов | Свои эмоции (`:name:`) загружаются файлом или по ссылке, с переключателями анимации и «Доступна друзьям». Эмоции со `sharedWith: all` доступны всем пользователям и друзьям в любом канале и в ЛС, бесплатно. В picker две вкладки: «Эмоции серверов» и нейтральные типографские «Символы». |
| Баннеры | Градиенты/фото у профиля и каждого сервера, видны в шапке, интро канала, профиле, карточках и на экране приглашения. |
| Приглашения | Вечная кастомная ссылка `dogapp.gg/<адрес>` (уникальна на базу) или обычная ссылка со сроком **ровно 3 дня**; отдельная страница `#/i/<code>`, просроченные ссылки блокируются. |
| Realtime | `/dogapp` в Firebase Realtime Database через REST (`GET/PUT/PATCH/DELETE`), опрос раз в 2 с. При недоступности базы — авто-фолбэк на `localStorage` с синком между вкладками. |
| Прочее | Реакции, ответы, редактирование, поиск, «печатает…», вложения, вставка картинки по ссылке, каналы, роли, онлайн-статусы. |

Смайлы как декоративный элемент интерфейса убраны: аватары и иконки серверов — монограммы, эмоции серверов — векторные значки, в picker вместо эмодзи-лица используются типографские символы. Логотип нарисован в SVG.

## Запуск

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Откройте `http://localhost:8000` (или preview-ссылку). Нужен именно HTTP: ES-модули не работают с `file://`. Подойдёт любой статический хостинг.

## Firebase

База прописана в `js/util.js`:

```
https://dogapp-52b84-default-rtdb.firebaseio.com
```

Данные в узле `/dogapp`. Адрес меняется в интерфейсе: «Настройки пользователя → Подключение».

Правила для демо (Firebase Console → Realtime Database → Rules):

```json
{
  "rules": {
    "dogapp": {
      ".read": true,
      ".write": true
    }
  }
}
```

Открытые правила подходят только для демо. Для реального проекта нужны Firebase Auth и проверки `.validate`. Пароли в текущей реализации хешируются на клиенте — это не замена серверной аутентификации.

При первом подключении к пустой базе заливаются демо-данные: 3 сервера, 7 участников, каналы, сообщения, эмоции, друзья, заявки и 4 приглашения.

## Структура

```
index.html          каркас: загрузка, вход, приглашение, рельса, сайдбар, чат, оверлеи
styles.css          Discord-like UI + экраны входа/звонков, адаптив
assets/logo.svg     логотип dogapp
js/util.js          экранирование, URL/цвета/баннеры, файлы и freeze GIF, шрифты, хеш пароля
js/icons.js         SVG-иконки
js/emojis.js        эмоции серверов (векторные значки) и нейтральные символы
js/seed.js          стартовые данные
js/store.js         REST-клиент Firebase + локальный фолбэк
js/auth.js          регистрация, вход, сессия, экран входа
js/friends.js       заявки, список друзей, поиск, блокировка, экран «Друзья»
js/calls.js         WebRTC-сигналинг, демо-звонки, голосовые каналы
js/render.js        рендер чата, форматирование текста, карточки приглашений
js/modals.js        настройки, приглашения, эмоции, каналы, профили, picker
js/app.js           события, экшены, формы, загрузка фото, роутинг #/i/<code>
```

## Горячие клавиши

- `Enter` — отправить сообщение
- `Shift + Enter` — новая строка
- `Esc` — закрыть окно / picker / отменить ответ

## Примечания

- Гостевой вход не требует пароля: uid генерируется и хранится в браузере.
- Кастомные ссылки — hash-роуты `#/i/<code>`, поэтому работают на любом статическом хостинге.
- WebRTC использует публичный STUN-сервер; если он недоступен, соединение возможно в локальной сети, а для демонстрации всегда есть демо-звонок. Разрешение на камеру/микрофон запрашивает браузер (нужен HTTPS или localhost).
- Синтаксис сообщений: `**жирный**`, `*курсив*`, `` `код` ``, `> цитата`, `@Имя`, `:emote:`, `![подпись](https://…/pic.png)`, ссылки.
