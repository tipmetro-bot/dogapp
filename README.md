# dogapp 🐕

Бесплатная копия Discord на чистом **HTML + CSS + JS** (без сборки, без фреймворков, без npm-зависимостей).
Загрузочный экран и интерфейс — в стиле Discord, но со своим характером: баннеры, эмоции серверов без Nitro и ссылки-приглашения с кастомным адресом.

> Всё бесплатно. Навсегда. 🐾

## Что умеет

| Фича | Как работает |
| --- | --- |
| **Загрузка как в Discord** | Логотип dogapp, прыгающие точки, сменяющиеся статусы, прогресс-бар и плавный переход в чат. |
| **Интерфейс Discord** | Рельса серверов, список каналов с категориями, чат с группировкой сообщений, список участников, панель пользователя, ЛС и экран «Друзья». |
| **Баннеры для себя и серверов** | Градиент (6 пресетов) или своя картинка по URL. Баннер виден в шапке сервера, в профиле, в интро канала, на экране приглашения и в карточках серверов. Меняется в «Настройках пользователя → Мой профиль» и «Настройках сервера → Обзор». |
| **Бесплатные эмоции серверов** | Кастомные эмоции (`:doge:`, `:bone:`, …) можно использовать **в любом канале и в ЛС**, без подписки. Picker показывает эмоции всех серверов, на которых ты есть. Свои эмоции добавляются по URL или загрузкой файла (PNG/GIF/WEBP до 200 КБ) во вкладке «Эмоции». |
| **Кастомная ссылка на сервер** | `dogapp.gg/любой-адрес` — не истекает, уникальна на всю базу, задаётся при создании сервера или в «Настройки сервера → Приглашения». |
| **Обычная ссылка = 3 дня** | Если кастомного адреса нет, генерируется код на 8 символов и `expiresAt = createdAt + 3 * 24 * 60 * 60 * 1000`. После истечения страница приглашения показывает «Срок действия ссылки истёк», кнопка входа не работает, в чате карточка помечается `истекла`. |
| **Экран приглашения** | Отдельная страница по адресу `#/i/<code>`: баннер сервера, иконка, число участников, счётчик срока действия и кнопка «Присоединиться». |
| **Realtime** | Сообщения, реакции, профили, эмоции, каналы и приглашения пишутся в **Firebase Realtime Database** через REST (`PUT` / `PATCH` / `DELETE`), состояние подтягивается раз в 2 секунды. Открой приложение в двух вкладках — чат общий. |
| **Ещё** | Реакции (в т.ч. кастомными эмоциями), ответы, редактирование и удаление своих сообщений, поиск по сообщениям, «печатает…», вложения-картинки, вставка GIF по ссылке, создание/удаление каналов, выход и удаление сервера, статусы присутствия. |

## Запуск

Ничего собирать не надо — это статический сайт. Из корня репозитория:

```bash
python3 -m http.server 8000 --bind 0.0.0.0
```

Открой `http://localhost:8000` (или preview-ссылку Arena). Важно открывать именно через HTTP: ES-модули не работают с `file://`.

Можно положить папку на любой статический хостинг (GitHub Pages, Netlify, Vercel static и т.д.).

## Firebase

База уже прописана в `js/util.js`:

```
https://dogapp-52b84-default-rtdb.firebaseio.com
```

Данные лежат в узле `dogapp` (`/dogapp.json`), чтобы не задевать другие ветки базы.
Адрес можно поменять в интерфейсе: **Настройки пользователя → Подключение** (сохраняется в `localStorage`).

### Правила

Для работы без авторизации в Firebase Console → **Realtime Database → Rules**:

```json
{
  "rules": {
    "dogapp": {
      ".read": true,
      ".write": true
    }
  }
}
```

⚠️ Это демо-правила: любой, кто знает URL, сможет читать и писать. Для реального проекта включи аутентификацию и проверки `.validate`.

### Что если Firebase недоступен

Приложение автоматически уходит в **демо-режим**: состояние хранится в `localStorage` и синхронизируется между вкладками через `storage`-событие. Если база доступна только на чтение (запрещён `.write`), после первой же неудачной записи тоже включается демо-режим с уведомлением. Статус подключения и текст ошибки видны во вкладке «Подключение».

При первом подключении к пустой базе автоматически заливаются демо-данные: 3 сервера, ~7 участников, каналы, сообщения, эмоции и 4 приглашения (2 кастомных + 2 временных).

## Структура

```
index.html          каркас: загрузка, рельса, сайдбар, чат, оверлеи
styles.css          весь Discord-like UI (~900 строк, CSS-переменные, адаптив)
assets/logo.svg     логотип dogapp (пёс в blurple-квадрате)
js/util.js          экранирование, URL/цвета/баннеры, даты, TTL, тосты
js/icons.js         SVG-иконки
js/emojis.js        стандартные эмодзи + бесплатные эмоции серверов (SVG data URI)
js/seed.js          стартовые данные для пустой Firebase
js/store.js         REST-клиент Firebase + локальный фолбэк
js/render.js        рендер чата, сообщений, форматирование текста, карточки приглашений
js/modals.js        настройки, приглашения, эмоции, каналы, профили, emoji-picker
js/app.js           события, экшены, формы, роутинг `#/i/<code>`
```

## Горячие клавиши

- `Enter` — отправить сообщение
- `Shift + Enter` — новая строка
- `Esc` — закрыть модалку / picker / отменить ответ

## Примечания

- Имя пользователя генерируется один раз и хранится в браузере (`dogapp_uid_v1`). Регистрации нет — это демо.
- Голосовые каналы отображаются, но звук/видео не реализованы (на клик показывается уведомление).
- «Кастомные ссылки» — это hash-роуты вида `#/i/my-server`, поэтому они работают на любом статическом хостинге без настроек сервера.
- Синтаксис сообщений: `**жирный**`, `*курсив*`, `` `код` ``, `> цитата`, `@Имя`, `:emote:`, `![подпись](https://…/pic.png)`, ссылки.
